Give the finish a starting point.

Set your finish date and time. Each row is a step; change its minutes, or select it to edit its name and prerequisites below the timeline.

  • Latest starts places each step as late as its connections allow. Early starts begins steps as soon as their prerequisites finish.
  • Orange steps have no spare time within this plan. If they take longer, the overall start moves earlier. There may be several such paths.
  • The hatched area shows the available start window for a flexible step. Connections that would create a circular dependency are disabled.
  • Independent steps may run at the same time. People and equipment are not assigned automatically. Add dependencies to keep shared work sequential.
  • Durations are elapsed minutes, including nights and weekends. Times use this browser’s local time zone. This page does not send reminders.

Your latest valid plan is saved in this browser when storage is available. Undo works during the current session. Copy the schedule to keep a portable text version.
