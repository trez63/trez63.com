CanvasForge Help

Build and iterate on a Business Model Canvas. Each block holds editable items.

  • ? or H — toggle this help
  • T — toggle light/dark theme
  • S — save canvas to JSON
  • O — open a previously saved JSON
  • R — reset to demo data
  • P — generate / refresh pitch summary
  • Esc — close help

On mobile, tap any item to edit, use the + buttons to add, and the × to remove. Completeness updates live. All data stays in your browser until you save.
