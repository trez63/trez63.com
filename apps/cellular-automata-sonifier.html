Controls

  • Space — Play / Pause evolution + sound
  • S — Single step
  • R — Randomize grid
  • C — Clear grid
  • T — Toggle theme
  • H or ? — This help
  • 1–5 — Select ruleset
  • Click / tap / drag — Paint cells

Each living cell in a row triggers a note from a pentatonic scale. New births create the melody. Save/Open preserves grid + settings as JSON.
