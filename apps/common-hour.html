A time to propose.

Find the common hour.

  1. Choose a reference day and zone. The slider covers actual 15-minute starts on that local calendar day. A daylight-saving transition can make the day longer or shorter.
  2. Add your people. Give each person a time zone, one daytime work window, and working weekdays. No checked weekdays means that person is unavailable.
  3. Move the time. The green strip marks starts that fit everyone. Other bars show partial overlap. The whole meeting must fit every selected person’s work window to count as a full match.
  4. Try the best overlap. Jump to the earliest start with the highest number of available people. Suggestions sample other equally good starts. If nobody is available, no time is presented as a good match.
  5. Keep the plan. Save downloads the complete workspace as JSON; Open restores it. Copy or export a proposal to review before you send invitations yourself.

Availability is based only on the work windows you enter. Holidays, calendar conflicts, and real-time status are not known. The model uses your browser’s time-zone database and checks actual 15-minute blocks; numeric UTC offsets distinguish repeated clock times.

Up to six people, 15–180 minutes per meeting, dates 2020–2040. No custom keyboard shortcuts: native slider arrow keys, Tab, Enter, Space, and dialog Escape keep their usual behavior. Changing the meeting name clears the app’s one-step Undo; native text undo stays available.
