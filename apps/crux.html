    Crux

    Type a plan, one task per line, and Crux computes the critical path (CPM) and then simulates the whole schedule thousands of times with PERT-beta durations to tell you how likely each finish date really is.

    Syntax

    start 2026-11-02      # first day
workdays on           # count Mon–Fri only
runs 5000             # simulations
Research   3-5-9      # optimistic-likely-pessimistic (days)
Spec       2-3-5  after Research
Build      10         # fixed duration
QA         4-9   after Spec, Build   # min-max

    Reading the chart

    Solid bars are the likely schedule; a dashed tail is the task's float (how late it can finish without moving the end). The percentage is how often the task sat on the critical path across all simulations. Tap any row for details and to jump to its line.

    Keys

    Single-letter keys are ignored while you type. Save downloads a file when Crux is opened directly from disk (the artifact viewer blocks downloads). Nothing leaves your browser.
