One structure.
Many possibilities.

  1. Edit the template. Write a handoff, introduction, project update, or publishing brief. Add slots like {{project_name}}.
  2. Fill the details. Each name gets one field. A value fills every matching occurrence, including multiline text. Values are inserted literally; they cannot contain formulas or nested template logic.
  3. Find the gaps. Empty slots appear in orange. Next empty field moves you to a missing value. Fix missing fields or malformed slots before exporting.
  4. Keep and reuse. Save downloads your entire workspace as JSON. Open restores it. Export .txt and Copy document produce the title followed by the completed text.

Values stay in the workspace when their slot disappears, so temporary template edits do not erase them. Clear unused values removes these stored details; Undo can restore them. Undo last action stays available until you type another edit; native text undo remains available in the editor. Saved JSON includes unused values until you clear them.

Limits: 20,000 template characters, 60 active field names, 300 slot occurrences, 2,000 characters per value, and 250,000 rendered characters. No custom keyboard shortcuts: native typing, Tab, Enter, and dialog Escape retain their usual behavior.
