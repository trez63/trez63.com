Get a feel for chance

  1. Fill the bag with blue plain tokens and coral marked tokens. The symbols keep them distinguishable.
  2. Choose a handful size. Keep tokens out removes each drawn token until the handful is complete. Put each token back makes it available for the next draw.
  3. Choose how many marked tokens you want. The exact probability updates immediately.
  4. Draw a handful or run 100 trials. Compare your outcomes with the exact distribution below.

Every trial starts with the full bag. Changing the bag or draw rules starts a new set of trials; Undo can recover the previous set.

Save keeps your settings and trial record in a local JSON file. Open restores them. Export trials CSV saves the result counts for a spreadsheet.
