FlowForge Help

  • Drag nodes to rearrange. Tap to select.
  • Use toolbar to add Start / Task / Decision / End nodes.
  • Select two nodes then press Connect (or C) to link them.
  • Edit label and type in the properties panel.
  • H Help   T Theme   S Save   O Open
  • N New Task   D Delete   C Connect   Esc Deselect
  • Save downloads a .json you can reopen later. Demo is pre-loaded.
