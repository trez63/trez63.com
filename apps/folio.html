Folio

Write Markdown on the left; Folio lays it out into real pages on the right — a table of contents with page numbers, running headers, headings kept with their text, paragraphs and tables split cleanly across pages. PDF prints exactly what you see.

Keyboard

Ctrl /Toggle this help Ctrl SSave document + layout as JSON Ctrl OOpen a saved Folio file Ctrl PPrint / save as PDF ,Layout settings ZZoom: fit → 100% → 150% TDark / light interface 1 / 2Write / Pages (phone) EscClose panels

Markdown

# Title ## Section **bold** *italic* `code` [link](url) - list 1. list > quote | table | --- rule, fenced ``` code, and \newpage to force a page break. With a cover page on, the first # heading and the paragraph after it become the cover.

Save / Open

Save downloads folio-YYYY-MM-DD.json (text + settings); Open restores it exactly. Downloads work when this file is opened directly (the artifact viewer blocks them).
