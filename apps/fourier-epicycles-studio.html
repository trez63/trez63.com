Fourier Epicycles Studio

Draw any closed path. The app computes its discrete Fourier transform and reconstructs it with rotating circles (epicycles).

  • Space or Play — toggle animation
  • D — draw mode
  • C — clear path
  • ↑ / ↓ — more / fewer terms
  • ← / → — slower / faster
  • T — cycle theme
  • S — save JSON
  • O — open JSON
  • ? or H — this help

On mobile, touch and drag to draw. Controls stay reachable at the top.
