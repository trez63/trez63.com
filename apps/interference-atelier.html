Interference Atelier

Place wave sources and watch real-time interference. Click/tap canvas to add or drag existing sources. Pre-loaded demo is already running.

  • Click/tap empty area — add source
  • Drag source — move it
  • A — add random source
  • C — clear all sources
  • Space — pause/resume
  • T — toggle dark/light theme
  • S — save composition as JSON
  • O — open previously saved JSON
  • R — randomize current sources
  • H or ? — toggle this help

Sources pulse with their frequency; brighter fringes show constructive interference.
