Ready for the next person.

From noise to a useful handoff.

  1. Use Load logs to paste or open a text file. The example is ready to explore.
  2. Select severity buttons, search for literal text, or select a sequence block to narrow the list. Reset filters shows everything.
  3. Select a recurring pattern to isolate similar messages. These are approximate groups, not proof of a shared cause.
  4. Expand a row to see its complete original line. Pin evidence with ☆, add notes, then use Copy brief.
  5. Save downloads a portable JSON investigation. Open restores it. Nothing is automatically stored when you close the tab.

Parsing: JSON lines recognize string fields level/severity, message/msg, and timestamp/time/ts. Plain text recognizes a level at the start, optionally after an ISO-style timestamp. Unknown lines remain “other.” Warning maps to warn; fatal/critical to error; trace to debug. Numeric severity codes are not guessed.

Sequence: the map follows physical line order, not elapsed time. Timestamps are displayed as supplied. Blank lines are skipped; stack-trace continuation lines remain separate events. Patterns lowercase messages and mask numbers, hexadecimal IDs, and UUIDs. Grouping can combine unrelated messages; inspect the originals.

Mobile: all actions have touch controls. Save supports downloads and file sharing when available. This app has no custom keyboard shortcuts; standard text editing and button keys retain their browser behavior.

Limits: 300,000 characters, 5,000 physical lines, and 50 visible events per page. Logs and notes remain on your device. Share only the evidence you intend to share.
