Nib

Every letter here is a bare skeleton of lines and arcs. A single pen nib is dragged along each skeleton, and the shape it sweeps out is the letter. Change the pen and the whole typeface changes with it.

  • Pen pad: drag to turn the nib and set its width. A flat nib at an angle gives thick and thin strokes, like a calligraphy pen.
  • Dials: contrast, nib shape, slant, x-height, width, bowl shape, wobble and spacing.
  • Glyphs: tap any glyph to see its skeleton and the pen stamps that build it.
  • Export .ttf: writes a real TrueType font you can install and use in any app.
  • Save / Open: keeps the design as a small JSON file and restores it exactly.

Save and Export download files. That works when this page is opened directly as a file; a hosted preview asks you to confirm each download first.
