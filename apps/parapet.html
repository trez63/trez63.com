Parapet

  
An offline auditor for HTTP response headers. Paste what curl -I or DevTools shows you — or, when parapet.html is hosted on the site itself, type a path and press Fetch — and get a grade, a finding-by-finding report with one-tap fixes, a map of every Content-Security-Policy directive, and the hardened set as nginx / Apache / Caddy / Express config. Nothing leaves this page, so it works on intranet apps no online scanner can reach.

Single-key shortcuts pause while you type in the editor; Ctrl/⌘ combos always work. Save downloads parapet-DATE.json (headers, tab, format, theme) and Open restores it — Save works when the file is opened directly; the artifact viewer blocks downloads.

  
Fetch: browsers let a page read only a few safelisted headers from another origin, and never Set-Cookie, so Fetch works for paths on the same site Parapet is served from (drop the file into that site's static folder) and reads everything except cookies; for other sites, or when opened from file://, paste curl -I output.

  
Grading: 100 weighted points across HSTS, CSP, framing, MIME sniffing, referrer, permissions, cross-origin isolation, cookies, disclosure, deprecated headers and CORS. A critical finding caps the grade at D.
