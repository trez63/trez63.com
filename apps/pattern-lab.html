Pattern Lab Help

Gray-Scott reaction-diffusion. Two chemicals U (feed) and V (catalyst) interact to form organic patterns.

  • Space / Pause button — pause/resume simulation
  • R — reset to current preset
  • T — toggle theme
  • H or ? — this help
  • S — save state as JSON
  • O — open saved JSON
  • 1–6 — quick presets
  • Mouse / touch drag — paint V catalyst
  • Scroll / pinch not used; use sliders

All state (params + grid) is saved/loaded. Works offline.
