Rail

  
Type a regular expression and Rail draws it as a railroad diagram: follow any path from the left dot to the right dot and you have a string it matches. Tap a box in the diagram or a line in Explain and the test text shows, in blue, exactly which characters that part captured in every match.

  
Flags g i m s u y are the usual JavaScript flags. Replace previews text.replace() live. Recipes load ready-made patterns.

  

    Ctrl/⌘ /this help
    Ctrl/⌘ Ssave pattern, flags, text and replacement as .json
    Ctrl/⌘ Oopen a saved .json
    Escclose help, or clear the selection
    Ttoggle dark / light
    Ffit diagram to width / actual size
    1 · 2 · 3Matches · Explain · Replace tab
  

  
Single-letter keys only work while you are not typing in a field. Save downloads a file when Rail is opened directly (double-click the .html); some embedded viewers block downloads. Nothing leaves your browser.
