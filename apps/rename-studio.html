RENAME STUDIO

Plan a batch rename before you touch a single file. Build a pattern, watch every new name update live, then copy the plan.

1 · Build your pattern

Tap a token chip to insert it where your cursor sits in the pattern. Anything you type is kept literally. {ext} is always added automatically if you leave it out.

2 · Live preview

The new name for every file updates as you type. Duplicates are flagged — fix the pattern or a file name before renaming anything for real.

These are sample files so the preview is alive on load. Add your own, remove any you don't need — nothing here touches your real files.
