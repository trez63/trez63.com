A second look, made simple.

  1. Put the original in Before and the new version in After.
  2. Choose Compare drafts. Underlines show additions; strikethroughs show removals. Arrow buttons jump between changed passages.
  3. Use Save for a portable JSON file. Open restores both drafts, the title, and your reading settings. Nothing is sent away.

On a phone: use Save, then your browser’s download controls or Share file → Save to Files. Open selects that JSON file again. Keep the HTML app itself, too.

One shortcut: Ctrl+Enter (Windows) or ⌘+Enter (Mac) compares the drafts. All actions also have buttons. Ordinary typing and browser shortcuts are left alone.

Comparison is exact and case-sensitive. Spaces and line breaks count as changes. The browser normalizes pasted line endings. Word counts use local word segmentation; punctuation-only changes may add no words. Highly complex edits use a clearly labeled block comparison. This tool does not judge grammar, truth, or legal meaning.

Drafts are not automatically stored. Save a file before closing this tab. Each draft can contain up to 20,000 characters.
