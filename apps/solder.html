Solder — a pocket circuit lab

Everything you draw is simulated live: real node voltages and branch currents (modified nodal analysis, backward-Euler transients, Newton iteration for LEDs). Dots show current flow; LEDs and lamps glow with real power.

Build: pick a tool, then drag on the board from one grid dot toward the next. Wires follow your whole drag; parts take one cell in the drag direction (drag direction sets battery/LED polarity).

Inspect: tap any part to select it, edit its value (SI suffixes work: 4.7k, 100u), flip it, or delete it. Tap a switch to toggle it. The scope plots the voltage across the selected part.

Keys: W wire · R resistor · V battery · C capacitor · S switch · D LED · L lamp · F flip selected · Delete/Backspace delete selected · Space run/pause · T theme · Esc deselect/close · ? or Ctrl/⌘ / help · Ctrl/⌘ S save · Ctrl/⌘ O open.

Save/Open write and read a JSON file (solder-YYYY-MM-DD.json). Downloads work when this file is opened directly in a browser; the artifact viewer blocks them.
