Daily Build 2026-10-23 — Tessera
TESSERAEscher-style tiling editor

Tessera

Shape one tile; the plane re-tiles itself. Each symmetry copies your free edges onto the others by translation, glide or rotation, so the pattern can never have gaps or overlaps.

drag ●
Move a handle on the highlighted home tile. Hollow dots are the mirrored copies.
double-click
Add a handle on a free edge.
alt-click / right-click
Remove a handle.
1 – 4
Symmetry: Translate (p1), Glide (pg), Spin (p4), Hex (p3).
R / Z
Random organic shape / undo.
Space
Breathe: animate the handles while the tiling stays perfect.
C / T / H
Cycle palette / toggle theme / hide handles.
S / P
Download the view as SVG (one path, many <use>) or PNG.
drag / wheel
Pan the plane / zoom. + − 0 also zoom.
