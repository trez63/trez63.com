Show the math & a few useful limits

Each score is a weighted average: add rating × importance for every active criterion, then divide by total importance. Zero means a criterion is switched off. Missing ratings on active criteria pause all rankings.

The colored bars show each criterion’s contribution. “Try a shift” searches every 0.1 step from 0 to 10, changes just one importance, and checks that an option leads every other option. All ratings and other priorities stay fixed. It is a local model, not a prediction.

This approach treats rating steps as equally spaced. Avoid double-counting similar criteria. Non-negotiables should be checked before scoring—remove an option that fails one.

Everything stays in this HTML file and your browser’s local storage. Save downloads an optional comparison backup; Open restores it. The app works without either.

Set a rating

Make the tradeoffs visible.

Start with a real choice. The example is a weekend plan; all the names, ratings, and priorities are yours to change.

  1. Name 2–5 options and 2–6 criteria. Keep each criterion distinct and phrase it so higher is better.
  2. Tap a rating to score each option from 1 to 5. Use the same scale across options.
  3. Move the importance sliders. Zero switches a criterion off. Ten gives it the greatest relative importance.
  4. Explore what would change your mind. Try a suggested shift; Undo brings the old priorities back.

Names and ratings save here automatically when storage is available. Use Save to keep a portable JSON backup. No account or internet required.
