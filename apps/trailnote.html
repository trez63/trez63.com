    BUILT FOR EXPLORING · WORKS OFFLINE

    Your route, point by point.

    1. Import GPX opens a local track or route file. The fictional example is ready to explore immediately.
    2. Move the slider, use the arrows, or tap the route to choose a point. The profile and measurements follow the same cursor.
    3. Write in Note at this point. Your words stay attached as you move the cursor. Select a route note to return to that spot. You can keep up to 40 notes.

    Save downloads a notebook file with the route, notes, units and cursor position. Open restores a saved Trailnote notebook. On an iPhone, use the offered share control to save to Files when available.

    Distance follows consecutive recorded points within each track segment. Gaps between segments are excluded. Elevation comes from the imported file; points without a height appear as gaps in the profile.

    The route drawing shows recorded geometry. It does not include terrain, roads or live navigation, and needs no device location. Very sparse or noisy recordings can affect measurements.
