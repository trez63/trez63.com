Live TurtleLoom

Parametric turtle graphics with real-time sliders. Move a slider and the shape rebuilds instantly. The code panel always reflects the current parameters so you can copy or extend it.

Sliders

  • Outer repeats — how many times the polygon is rotated
  • Side length — length of each edge
  • Polygon sides — 3 = triangle, 4 = square, 5 = pentagon…
  • Turn step — degrees added after each polygon
  • Hue — pen color (HSL)

Commands (free editor)

FORWARD / FD, BACK / BK, LEFT / LT, RIGHT / RT, PENUP / PU, PENDOWN / PD, HOME, CLEAR, COLOR r g b, REPEAT n [ … ]

Shortcuts

R or Ctrl+Enter — run code
C — clear · T — theme · D — PNG
? / H — this help · Esc — close
