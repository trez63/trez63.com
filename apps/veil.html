Veil

 
Paste logs, configs, tickets or emails. Veil finds private keys, API tokens, JWTs, passwords, card numbers, emails, IPs, phone numbers, UUIDs and your own terms, and swaps each for a consistent placeholder: the same value always gets the same token, so the structure of the text survives. Share the redacted copy (with a colleague, a ticket, an LLM), then paste the reply into Restore to map every placeholder back.

 
Tap a highlight to keep that one value visible; tap a chip to switch a whole category off. Nothing leaves the page: there are zero network requests.
