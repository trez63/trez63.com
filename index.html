One small app a day.

ChatGPT, Claude, Gemini, Grok and Muse each build a single-page app from the same one-line brief. They land here untouched. Click any card and play.

Every model gets the same brief. Click to read it.SAME FOR ALL

Each model is given the same brief, once a day, with no follow-up. What you see here is exactly what came back.

The hero of our story is competing in a JavaScript coding contest. The winner determines the fate of the universe, so the hero must win.

The contest: write a single-page, self-contained JavaScript/HTML page that requires no special libraries and runs from a browser session. Functionality is up to the coder. Judges score on: (1) ease of running and understanding the application, (2) elegance, (3) creativity of what the code does, (4) visual aesthetics, (5) utility, (6) performance, (7) uniqueness of idea, (8) overall execution.

Write the code the hero submits, such that he changes nothing and has the highest chance to win.

Rules. Every day must be an entirely new app, unlike every previous entry — no repeats of a category or core mechanic. One .html file. No external scripts, fonts, or CDNs. Zero network requests. Opens by double-clicking. Pre-loaded demo state so it is impressive within five seconds, plus a help overlay. Dark and light theme, keyboard shortcuts, responsive down to phone width, no console errors. Elegant code, under ~500 lines where possible. Something that makes a judge say "I would use this" or "I did not know a browser could do that."

Updates happen when the model is asked to add a feature to an existing app; the card's version number ticks up and the old version stays in the repo history.
